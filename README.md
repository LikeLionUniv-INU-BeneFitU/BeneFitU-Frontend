## 🌟 주요 기능 (Key Features)

대학생 개개인의 조건에 맞는 장학금을 스마트하게 매칭하고, 신청부터 결과까지 전 과정을 체계적으로 관리하는 핵심 기능들을 제공합니다.

### 1. 내 정보 기반 맞춤 장학금 추천 (Custom Recommendation)
* **맞춤형 장학금 추천:** 사용자가 입력한 프로필 정보(학교, 학년, 성적, 소득 분위 등)를 바탕으로 신청 가능한 최적의 장학금을 자동 매칭합니다.
* **직관적인 분석 정보:** 단순 정보 나열이 아닌 **추천 이유**와 **지원 가능성**을 분석하여 함께 제공합니다.
* **스마트 카테고리 필터링:** 국가, 기업·재단, 지역, 조건별 카테고리를 분리하여 원하는 장학금을 더욱 빠르게 검색하고 탐색할 수 있습니다.

### 2. 신청 현황 및 히스토리 관리 (Application Management)
* **진행 상태 추적:** 내가 신청한 장학금들의 진행 상황(신청 완료, 심사 중, 선발 완료 등)을 실시간 대시보드로 손쉽게 추적합니다.
* **통합 관리 기능:** 매 학기 흩어져서 수기로 관리하기 어려웠던 장학금 신청 히스토리를 대시보드 한곳에서 투명하게 관리할 수 있습니다.

## 📂 폴더 구조 (Folder Structure)

```text
src/
├── api/             # API 연동 및 통신 관련 모듈
├── assets/          # 이미지, 폰트 등 정적 리소스
├── components/      # 재사용 가능한 공통 컴포넌트
├── hooks/           # 커스텀 훅 관리
├── pages/           # 페이지 단위 컴포넌트
├── styles/          # 전역 스타일
├── App.jsx          # 최상위 라우터 및 메인 컴포넌트
└── main.jsx         # 애플리케이션 진입점 (Vite Entry)
```
